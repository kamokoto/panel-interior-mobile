# Успенка Сервис — каталог материалов

Статический сайт с фотографиями, 3D-просмотром, поиском, подборкой и расчётом количества резиновой плитки.

## Ассортимент
- 49 декоративных ПВХ-панелей из прежнего каталога.
- 3 оттенка шовной вагонки 200 мм.
- 5 вариантов резиновой плитки.
- 2 типоразмера подставочного профиля (23 и 38,5 мм); у профиля 23 мм две фотографии.
- 11 образцов фурнитуры.

Всего 70 карточек. Использованы все 22 фотографии из четырёх новых архивов; HEIC преобразованы в WebP с учётом ориентации.

## Просмотр и сборка
Готовые файлы сайта: index.html, studio.css, showroom.css, studio.js, catalog-data.js и каталоги assets, images, products, scene, textures. Загружайте их с сохранением структуры. Нужен HTTP/HTTPS-сервер, открытие index.html через file:// не поддерживает загрузку 3D-сцены.

Исходники находятся в source. Для пересборки установите зависимости из package.json (`npm install`), затем выполните `npm run build`.

## Уточнения по содержанию
Новые 3D-модели — иллюстративные схемы по фото, а не производственные CAD-чертежи. Размеры, не указанные однозначно в исходниках, не выдуманы. Для плитки из файла «35 35 30» требуется уточнить единицы и размеры. Название декоративного плинтуса без подписи описательное. Совместимость профилей, цены, наличие, адрес и часы работы требуют информации от компании.

Кнопка «Открыть в почте» формирует mailto с подборкой и открывает почтовую программу посетителя. Посетитель самостоятельно отправляет письмо. Серверной отправки и хранения заявок нет. Подборка сохраняется только в браузере посетителя; доступны копирование и скачивание текста.

## Проверка 16 октября 2026
Проверены ширины 320, 390 и 1440 px; горизонтального переполнения страницы нет. Проверены фильтры пяти групп, поиск, пустое состояние, карточки с фото, новые 3D-режимы, прежние режимы ПВХ, подборка и её сохранение после перезагрузки, удаление из подборки, передача расчёта в запрос. Расчёт 10 м² с 10% запасом = 44 плитки 500 × 500 мм; нулевая площадь блокирует расчёт. Ошибок JavaScript при проверке не обнаружено.

Мобильная проверка выполнена в браузере с заданной шириной. Физический iPhone/Safari в этой среде недоступен, поэтому финальный просмотр на настоящем устройстве остаётся полезным.
