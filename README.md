# Panel Interior — mobile demo

Демонстрация адаптивного каталога отделочных панелей с интерактивной 3D-моделью.

Все ресурсы размещены локально. Серверная часть и отправка заявок не подключены.
3D-профиль является демонстрационной схемой и требует согласования перед использованием в коммерческом проекте.

GitHub Pages: публикация из ветки `main`, папка `/ (root)`.
