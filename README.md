# Успенка Сервис

Каталог материалов и комплектующих: 74 позиции в шести разделах.

Главная представляет направления производства и применение продукции. Раздел «О нас и контакты» содержит информацию о предприятии, телефоны, карту и реквизиты из предоставленной карточки предприятия. Иллюстрации применения подписаны как визуализации.

- Панели ПВХ — 22.
- Термопереводные панели — 30.
- Вагонка шовная — 3.
- Резиновая плитка — 5.
- Подставочный профиль — 3.
- Фурнитура — 11.

Для каждого товара доступны фотографии, характеристики и интерактивное рассмотрение конструкции при прокрутке. Увеличенные сечения иллюстрируют устройство по фотографиям и не заменяют размерный производственный чертёж.

Подборка и комментарий к заказу хранятся в браузере. Запрос открывается черновиком в почтовой программе посетителя; серверной отправки нет. Пустая подборка не отправляется. Поиск учитывает варианты е/ё и записи размеров (500 × 500, 500x500).

Сайт: https://kamokoto.github.io/panel-interior-mobile/

Публикация GitHub Pages: ветка `main`, папка `/ (root)`. Файлы готовы для статического хостинга; зависимости и серверная сборка не требуются.
